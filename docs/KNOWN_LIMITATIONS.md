# Current known limitations

Aegis is an unfinished internal demo preview. Default mode is Observe. The gateway's WAF acts only on HTTP requests passing through its configured route. A matched rule is not proof of a successful exploit; a passing synthetic test is not proof an arbitrary application is secure.

The current configuration supports the bundled Go demo and fixed hostname/origin only. Production TLS, custom app registration, trusted CDN proxy ranges, rate-limit controls and rule-expiry scheduling are not implemented. Docker origin ports are not published. Only loopback gateway and controller ports are published; this is not a host firewall audit or an HA deployment.

The controller and gateway can fail independently. Controller/collector loss leaves the current gateway policy active. Gateway failure causes an outage; no automatic origin bypass is provided. Gateway restart uses its own persisted active configuration. Controller crash during a leased fixture times out without a passing report. Remaining crash windows, disk-full behaviour, upgrade/restore and volume corruption must pass fault injection before release.

Scanner parsing, owner-scoped read-only repository registration and durable offline scan requests/results exist. Provisioned mounts are bound to one owner; arbitrary browser host paths and remote cloning are unavailable. Current map responses are capped at 60,000 bytes. Pinned Semgrep/Gitleaks/Syft/Bandit compatibility is tested against private snapshots. A native one-shot worker connects the private controller queue, source capture, fixed offline tools and normalized receipt/result ledgers with an independent container deadline guard. The owner API can enqueue/list scans, read admission status, cancel jobs and read immutable T0 suite indexes. The Scans console presents read-only request consent, status, cancellation and static suite summaries. Selected scan results have normalized, conservatively deduplicated finding details and bounded filters/pages. Owner review dispositions are stored separately with immutable revision history; they do not change scanner proof or suppress source claims. Global cross-job finding history, review-history browsing/export, AST-aware equivalence and proof promotion remain unfinished. Native operator-UID execution does not establish deployed Compose UID 10001 worker/socket pairing or background service availability. The operator can observe selected original-engine sandbox metadata and reported host files. A separate scoped private identity can read controller-recorded launch/workspace context; it authenticates metadata origin under local-host trust, not host cleanup. File-based observations retain their false authority flags. Active leases, incomplete allocations and queued late starts remain unexcluded. Independent cleanup verification/release is absent: completed, failed, cancelled and timed-out executions keep admission held. A queued job does not prove a worker is available, and a terminal result does not prove resource absence. Host SIGKILL workspace recovery is available as an explicit journalled operator command and refuses changed engine identity; automatic recovery remains incomplete. Offline vulnerability databases, freshness policy, comprehensive repository/lockfile coverage and user-configurable retention remain incomplete; fixed WAF fixture jobs have durable leases and exact owner-approved scopes. Zero findings never establishes safety. Inventory does not execute repository scripts. Symlinks and oversized input are rejected.

The tenant-isolation challenge uses only bundled trusted code and synthetic users. Arbitrary customer code/patch execution is unavailable until a separate disposable VM boundary exists. Docker isolation alone is not presented as sufficient for that feature. Findings require declared owner semantics and independent verification.

AI is off by default and no provider is required for the demo. Desktop AI pairing, MCP permissions, provider adapters and real provider GUI tests remain unavailable. No raw secrets or repository content are uploaded automatically.

Local tests and hashes are not independent sign-off or publisher signature validation. Public beta is NO-GO until every H7 gate has actual evidence, including independent installation and security/legal review. No production, volumetric DDoS, human-parity red team, exhaustive business-logic, or absolute protection claim is made.

An opt-in journaled local scanner backend records create/start/remove uncertainty across restart; it has a read-only existing-journal status command. It is not an exclusive engine broker or an independently authorized cleanup verifier. Uncertain mutations quarantine that namespace with no trusted repair/reset yet. All controller cleanup admission remains held. See the journaled scanner operator guide and ADR 042.
